# Поля рубрик PRO v6 (формат данных для Редактора)

Один JSON на рубрику: `node render.js <id> --data <файл> --out <папка>`. Можно передать и `{"evc": {...}}`.
Заполнять можно не всё: пропущенные поля берутся из образца в `data/<id>.json` (массивы заменяются целиком).
Текст — HTML: `<b>…</b>` выделяет, `<br>` — перенос. Фото — только `img/<файл>` из `credits.md`; новое фото — сначала файл в `img/` и строка в `credits.md` (автор, лицензия PD/CC0/CC BY, ссылка).
Цифры — только из источника с датой. Без советов «купить/продать», в `src` — «Не является инвестиционной рекомендацией».

## `evc` — «События дня» #СОБЫТИЯ (каждый вечер, автомат). Образцы: `data/evc.json` (23.10), `data/evc_long.json` (проверка длинного текста)
| Поле | Что | Пример / предел |
|---|---|---|
| `tag` | метка вверху | `"СОБЫТИЯ"` |
| `day` | день на обложке | `"Пятница, 23 октября"` |
| `k`, `sub` | надзаголовок и строка под днём | `"События дня · итоги · время МСК"` |
| `cover` | 2 фото обложки | `["img/cbr.jpg","img/nysesign.jpg"]` |
| `items[]` | события, **до 6** (лишние не рисуются; на обложке не влезло — «+ ещё N») | см. ниже |
| `sum` | итог дня: `[[флаг, текст], …]`, 3–4 строки | `["🇷🇺","<b>Россия:</b> ставка 14% — …"]` |
| `next` | «Главное впереди»: `{k, t, s}` | `{"k":"ГЛАВНОЕ ВПЕРЕДИ","t":"Ср 28.10 · 21:00","s":"Решение ФРС …"}` |
| `src`, `ph` | источники + оговорка; авторы фото (© строка) | |

`items[]` — одно событие = один слайд:
| Поле | Что |
|---|---|
| `tm`, `fl`, `who` | время МСК, флаг, кто публикует (`"16:45"`, `"🇺🇸"`, `"S&P Global"`) |
| `t` | название (длинное — кегль уменьшится) |
| `big` | крупная цифра (`"56,0"`, `"14%"`) |
| `img` | фото события или `""` — тогда большой флаг |
| `nums` | шкала: `[["Факт","56,0"],["Прогноз","55,4"],["Было","55,9"]]`; нет значения — `"—"` (бейдж «к прогнозу» не появится) |
| `vd`, `vt` | `better` / `worse` / `""` и текст: «Лучше ожиданий» / «Хуже ожиданий» / «Как ждали» |
| `s` | суть одной строкой (на обложке) |
| `hint` | что за показатель, 1 фраза (`<b>Индекс PMI</b> — …`) |
| `why`, `fol`, `nx` | «Почему так», «Что следует», «Что дальше» — 1–3 фразы; длинное ужмётся, совсем длинное сократится «…» |
| `mk` | «Для рынка», до 3 плиток: `[["up"/"dn"/"eq", "Доллар", "поддержка", "пояснение 1 фраза"], …]` |

## `monc` — Пн «Неделя впереди» (обложка + Пн–Пт + «Три вопроса»). Образец `data/monc.json`
`dates`, `pics` [[фото, подпись]×3], `k`, `title`, `when`, `lead`, `week` [[«ПН», «02.11», сильное 0/1, строка]×7],
`days[]` {`sub` строка на обложке, `sd` «ПН», `dn` «Понедельник», `dd` «02.11», `hi` 0/1, `big` время, `fl`, `t`, `mk` метки рынков `ru|w|us|c|oil`, `img`, `cap`, `w` что это, `ev` [[время, событие]…], `sc` [[метка «ЕСЛИ…», текст]…]},
`qs` [[вопрос, почему важно, когда ответ]×3], `src`, `ph`.

## `tuec` — Вт «Гайд недели» (обложка + 3 вывода + тест + ответ). Образец `data/tuec.json`
`img`, `k`, `title`, `lead`, `st` [[цифра, подпись]×3], `lbl`, `toc`, `take` [[заголовок, текст]×3], `quiz` [вопрос, [варианты]] — 1 или 3 вопроса, `ans` [[буква, пояснение]], `nxg`, `src`, `ph`.

## `thuc` — Чт «Нарратив недели» (5 слайдов). Образец `data/thuc.json`
`k`, `title`, `people` [[фото, имя, должность]×2], `lead`, `up` [[факт, пояснение]…] — что тянет вверх, `down` — что держит, `you` [[что, up|dn|eq, метка, текст]…], `out`, `wt` [время, событие], `src`, `ph`.

## Ср / Пт / Сб / Вс — карусели Арт-директора (`ad-v6.html`)
Пока свёрстаны на неделю 02–08.11 без полей данных: `node render.js ad [wed|fri|sat|sun] --out …`. Перевод на поля (`--data`) — следующий шаг пакета (Дизайнер, до 28.10); поля согласуются с Редактором.
