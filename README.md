# Пульс рынка — сборщик новостей

Собирает новости рынков (RSS, публичные Telegram-каналы), делает выжимки ИИ (Gemini, запасной — OpenRouter)
и отправляет их на сервер бота @ime_news_01_bot. Запускается сервером бота каждые 30 минут.

Ключи хранятся только в секретах GitHub (Settings → Secrets) и в коде не встречаются.
